# QUOTE → SOW CHECKLIST — Non-legal operating notes

**Not legal advice.** This is a freelancer operating checklist so you do not send a quote or SOW-shaped doc with holes. Binding terms live in **your** proposal/contract/lawyer review—not in this pack.

**Prospect:** `[Company]` · **Brief status:** Draft / Locked  
**Checklist date (ET):** `[YYYY-MM-DD]`

---

## A. Before you open the quote doc

- [ ] `SCOPE-BRIEF.md` exists with outcome + deliverables + exclusions.
- [ ] Decision-maker named (not `GAP`). If GAP → stop; reschedule or Script B recap.
- [ ] Open questions ≤3 and either answered or explicitly “quote assumes X.”
- [ ] Soft “make it pop” / maybe-payments parked **Out** or written as priced line items.
- [ ] Hard date vs budget band checked for impossibility (flag if date needs more scope cut).
- [ ] You are not still doing free architecture email threads.

---

## B. Quote contents (minimum)

- [ ] Restate outcome in one sentence (from brief).
- [ ] Deliverables list matches brief (no surprise extras).
- [ ] Exclusions list visible (copy from brief §3).
- [ ] Assumptions visible (copy from brief §4).
- [ ] Price or range + what moves the number (from `PRICING-WORKSHEET.md`).
- [ ] Deposit amount + when work starts.
- [ ] Timeline as milestones (not a fantasy Gantt).
- [ ] Validity window (e.g. quote good for 14 days).
- [ ] How change requests work (one paragraph, non-legal).
- [ ] Link or attach the locked scope brief.

---

## C. SOW-shaped doc (if you use one)

Treat as **commercial clarity**, then have counsel review if stakes warrant.

- [ ] Parties / project name correct.
- [ ] Scope = locked brief (incorporate by reference or paste).
- [ ] Payment schedule matches quote.
- [ ] Acceptance criteria per major deliverable (short).
- [ ] Kill / pause path stated in plain language (your policy—not invented here as %).
- [ ] No leftover TODO / TBD / lorem in client-facing PDF.
- [ ] You did **not** paste this pack’s templates as if they were lawyer MSAs.

---

## D. Send gate

Send quote / SOW only when:

1. Brief acknowledged or you explicitly quote “subject to brief confirm,” **and**
2. Decision-maker reachable for redlines, **and**
3. You would be willing to start if they pay the deposit tomorrow.

If any fail → send `FOLLOW-UP-EMAILS.md` Email 1 (brief) or close/lose—not a soft quote.

---

## E. After they say yes (deposit path)

- [ ] Deposit received (or signed + scheduled per your terms).
- [ ] Open `HANDOFF-TO-PRODUCT2.md` — switch to Freelancer Client Onboarding Kit ($39) for Week 0.
- [ ] Do **not** keep using only this close kit as your delivery OS.

---

## Anti-patterns

| Anti-pattern | Fix |
|--------------|-----|
| Quote before brief | Brief first; quote second |
| “TBD scope, fixed price” | Cut scope or use discovery spike |
| Hidden exclusions | Paste Out list into the quote |
| Endless revision of quote as free consulting | Cap redline rounds; paid spike otherwise |
