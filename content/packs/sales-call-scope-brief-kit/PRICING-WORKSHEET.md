## 3. Commercial shape

Pick one primary shape:

| Shape | When | Quote expression |
|-------|------|------------------|
| Fixed project | Brief locked, Out list strong | One number + deposit % |
| Fixed + change orders | Mostly locked | Base + stated change path |
| Weekly / sprint | Ambiguity high but trust high | Weekly rate × expected weeks |
| Paid discovery spike | Decision-maker OK but scope fog | Small fixed spike → then project quote |
