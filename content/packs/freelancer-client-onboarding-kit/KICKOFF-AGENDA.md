# Kickoff Agenda — Timed + Decision-Lock List

**Product:** Freelancer Client Onboarding Kit (AI Coding Ops)  
**Default length:** 45 minutes (30 min possible for tiny scopes).  
**Rule:** No kickoff ends without clearing or dating every decision-lock item.

## Timed agenda (45 min)

| Min | Block | Owner | Outcome |
|-----|-------|-------|---------|
| 0–3 | Welcome, roles, how we’ll use the brief | You | Everyone knows Project Brief is source of truth |
| 3–10 | Problem, users, one-sentence promise | You + client | Promise read aloud; corrected if wrong |
| 10–18 | Goals / non-goals + in/out checklist | You | Non-goals explicit |
| 18–25 | Milestones, dates, revisions policy | You | Dates on calendar; revision rounds agreed |
| 25–32 | Access & owners walkthrough | You + admin | P0 access requests assigned |
| 32–40 | **Decision-lock list** (below) | Decision-maker | Each item: Decide / Defer with date / Park out-of-scope |
| 40–45 | Comms norms, next demo date, close | You | Channel + SLA + next touchpoint |

### 30-minute cut

Drop deep access walkthrough to async; keep promise, in/out, milestones, decision-lock, next demo.
